# Supply Chain Analytics Dashboard

Power BI dashboard analyzing global supply chain data across markets, regions, and customer segments.

![Dashboard](Screenshot%202026-10-05%20102050.png)

## Tools Used
- Power BI

## Dataset
DataCo Supply Chain dataset (CSV, included as a zip file in this repository).

## Files
- `Supply_Chain_Dashboard_-_Aswitha_L.pbix`: the Power BI dashboard file
- `DataCoSupplyChainDataset_csv.zip`: the dataset

## Dashboard Includes
- KPI cards: Total Sales, Total Profit, Total Orders, Profit Margin %, Late Delivery %
- Sales and profit trend over time
- Sales by product category
- Ship mode and delivery status breakdown
- Market performance table
- Filters for Date, Market, Order Region, Customer Segment, Category, and Shipping Mode

## Key Insights
- Total sales of 36.78M with a profit margin of 10.78%
- Over half of all orders (54.83%) are delivered late, and every market is between 54% and 55%
- Europe and LATAM generate the highest sales
- USCA has the highest profit margin (11.14%)
- Fishing is the top-selling category
